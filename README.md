# Ashtavinayak City Security Management System

## Project Overview

Ashtavinayak City Security Management System is a web-based residential security management system developed to manage visitor registration, resident approval, visitor entry and exit tracking, and visitor history.

The system provides a centralized digital workflow for Security personnel, Residents and the Boss/Administrator.

## Key Features

- Security Login and Authorization
- Security Dashboard
- Visitor Registration
- Mobile Number Validation
- Resident and Flat Selection
- Pending Visitor Approval
- Telegram-based Resident Approval
- Approve / Disapprove Visitor Requests
- Visitor Entry Tracking
- Visitor Exit Tracking
- Visitor History
- Resident Management
- Boss / Administrator Dashboard
- Automatic Browser Opening

## Visitor Workflow

Security Login
→ Register Visitor
→ Validate Details
→ Select Flat / Resident
→ Create Pending Request
→ Send Telegram Approval
→ Resident Approves / Disapproves
→ Entry / Rejection
→ Exit Tracking
→ Visitor History

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Telegram Bot API
- Gunicorn
- Render

## System Architecture

The application uses Flask for backend processing, SQLite for data storage, HTML/CSS for the web interface and Telegram Bot API for resident approval communication.
